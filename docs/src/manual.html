Marathi News Intelligence · User manual

How to run and use the demo

Everything you need to open the demo, use each tab with your own Marathi text, and switch on the full models. No technical background needed.

Quick start — 30 seconds
  1. Open the file Marathi-NLP-Demo.html (double-click it).
  2. Click a tab: Morphology, Search or Full pipeline.
  3. Type or paste Marathi text. Results appear on the spot.

1What you need

The demo can run in three ways. Most of the time you only need the first one.

Way to runWhat you needWhat you get
A. Just the web page
recommended		 Any browser (Chrome, Edge, Firefox, Safari). No installation. All three tabs work on any text you paste. Category, sentiment and entities use small built-in models. Translation needs internet.
B. Web page + model server Python 3.10 or newer, plus one command left running. Same page, but category, entities, sentiment and translation use the full, more accurate models.
C. Streamlit dashboard Python, and about 10 minutes of one-time setup. A second app that also searches all 3,000 articles and can fetch today's news.

2Opening the demo

If you already have the project folder

  1. Open the folder Marathi-news-intelligence-pipeline.
  2. Double-click Marathi-NLP-Demo.html. It opens in your web browser.

If you are getting it from GitHub

The project is at github.com/anishc23/nlp-project. GitHub shows HTML files as code, so you have to download the page first:

  1. Go to the repository and open Marathi-news-intelligence-pipeline, then Marathi-NLP-Demo.html.
  2. Click the Download raw file button (the arrow icon at the top right of the file view).
  3. Double-click the downloaded file.

To get the whole project instead, click the green Code button, then Download ZIP, and unzip it.

Good to know

The page is one file of about 4 MB. You can email it, copy it to a pendrive, or open it on a phone. Everything except translation works offline. The internet is only used for nicer fonts and for English translation.

4Tab 1 — Morphology

Marathi joins what English says in several words into one word. For example घरांमधून means "from inside the houses". This tab splits such words back into their pieces.

Look at one word

  1. Type a Marathi word in the box, or click one of the grey example buttons under it.
  2. The coloured blocks show the result. The dark green block is the root (the basic word). The grey blocks are the endings that were removed.

Paste a sentence or a whole article

  1. Paste any Marathi text into the same box.
  2. You get a table with every word, its root, the endings removed and their grammar labels, plus three numbers at the top: how many words, how many had an ending, and how many different words are left after reducing them to roots.

What the notes in the table mean

—The word had no ending. It is already a root.
exception listA word the analyser handles with a fixed answer, so it is not cut wrongly (for example सरकारने stays सरकार).
final vowel normalisedOnly the last vowel sign was dropped, so related forms (शाळा, शाळेत) end up with the same root.

Common grammar labels

LabelMeaningExample ending
PL.OBLplural form before another endingां
LOC"in / at"त, मध्ये
ABL"from"पासून, मधून, तून
GEN"of"चा, ची, चे, च्या
DAT"to / for (a person)"ला, ना
INS"by"ने, नी
BEN"for (the sake of)"साठी
PST / FUT / PRSpast / future / present verb endingsले, णार, तो

5Tab 2 — Search

There are two search engines over the same 400 news articles. The only difference: the right-hand one reduces every word to its root first (using the Morphology tab's analyser); the left-hand one does not.

Run a search

  1. Click the Search tab. The query न्यायालय ("court") is already filled in.
  2. Type or paste any Marathi word or phrase in the box, or click a grey example button.
  3. Compare the two big numbers: results without morphology (left, red) and with it (right, green).

The line under the results explains what happened. For some words both sides find the same number, because the articles use the word in exactly the same form:

Add your own articles to the search

  1. Under the results, click Add your own articles to the index.
  2. Paste a headline and the article text, then click Add to both indexes.
  3. Search for a word from your article. It appears in the results marked YOUR ARTICLE, with a topic chosen automatically.
Note

Added articles are kept only until you reload the page.

6Tab 3 — Full pipeline

This tab takes a whole news article and runs every stage on it.

Analyse an article

  1. Click the Full pipeline tab. The first example is already analysed.
  2. To try your own: click Clear, paste a headline (optional) and the Marathi article text. A copied news article from any Marathi site works well.
  3. Click Analyse (or press Ctrl + Enter, ⌘ + Enter on a Mac).
  4. Or pick one of the eight ready-made examples from Start from an example.

Reading the results

The results appear below as a stack of boxes, one per stage, in the order the pipeline runs them.

BoxWhat it shows
Input articleYour headline, how many words it has, and what share of them carry a grammar ending.
D · CategoryThe three most likely topics out of 12 (Politics, Sports, Health…) with confidence bars.
E · SummaryThe three most important sentences of the article, in their original order.
G · EntitiesNames found in the text, grouped as Person, Organization, Location, Date, Designation and so on.
F · SentimentThe overall tone (Positive, Neutral or Negative), a colour bar, and the tone of each summary sentence.
A · English translationA button that translates the headline and summary to English (see section 7).

The small grey label on each box

The top-right corner of each box says which model produced it:

in-browser · 83% agreementA small model built into the page. The number is how often it gives the same answer as the full model, measured on 1,362 articles it had never seen.
full modelThe real, large model, used when the model server is running (section 8).
TextRank · same algorithm as PythonThe summary uses exactly the same method as the Python project, so it is identical either way.
Expect some mistakes from the in-browser models

The built-in entity finder is the least accurate part (it agrees with the full model about 72% of the time). In the example above it wrongly marks विजय ("victory") as a person's name. For the most accurate results, start the model server (section 8).

7English translation

  1. After analysing, scroll to the A · English translation box and click Translate to English.
  2. The page first loads the translation program. If one download site is blocked on your network, it automatically tries three others; the status line shows which one it is trying.
  3. The first time only, the page then downloads the translation model (about 900 MB). A progress line shows how much has arrived. This takes a few minutes on a normal connection.
  4. The headline and summary appear in English. The model is saved in the browser, so later translations skip the download and take only seconds. Keep an internet connection on, though: the page still loads the small translation program itself from the internet.
Tips
  • For the ready-made examples there is also a Show saved translation button, which is instant and needs no internet.
  • Do the first translation at home, before the presentation, so the model is already saved. Use the same browser on the day.
  • If the model server is running, translation goes through it instead: no download, and faster.

8Using the full models (optional)

The page can hand your text to the project's real, full-size models, which are more accurate. You need Python 3.10 or newer.

One-time setup

Open a terminal (Mac: Terminal; Windows: Command Prompt) in the Marathi-news-intelligence-pipeline folder and run:

python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

Every time

  1. In that folder, run python app/server.py and leave the window open.
  2. Open (or reload) Marathi-NLP-Demo.html.
  3. Click Analyse. The badge next to the button changes to Full models · local server, and the boxes say full model.
  4. When finished, go back to the terminal and press Ctrl + C to stop the server.

Good to know
  • The first Analyse after starting the server downloads the models (about 5 GB, once) and loads them. That first run can take a while; after that each article takes a few seconds.
  • The server only accepts connections from your own computer.
  • If the server stops, the page automatically goes back to its built-in models.

9The Streamlit dashboard (optional)

A second app that works over all 3,000 processed articles. After the one-time setup in section 8, run these once (they take about 10 minutes and download the datasets):

python scripts/download_data.py
python scripts/build_corpus.py --limit 3000
python scripts/build_index.py --plain-bm25

Then start it any time with:

streamlit run app/dashboard.py

It opens in the browser with five tabs: Search (all 3,000 articles, with topic and tone filters), Overview (topic and tone charts), Entity tone (how a person or party is covered), Morphology, and Analyse (paste text, or fetch today's news from BBC Marathi, ABP Majha and Lokmat).

10Problems and fixes

ProblemWhat to do
GitHub shows lines of code instead of the page Use Download raw file and open the downloaded file (section 2).
Marathi letters look plain or slightly different That is only the font; without internet the page uses your computer's Marathi font. Everything still works.
"That doesn't look like Marathi text" The page only analyses text in Devanagari script. Paste Marathi, not English or romanised Marathi.
The summary says "Too short to summarise" No sentence had three or more words. Paste full sentences ending with । . ! or ?
The summary is the whole text With three sentences or fewer there is nothing to shorten. Paste a longer article.
"Translation failed: Could not load the translation program — this network blocks …" Your network (often mobile data) blocks all four sites the translator is downloaded from. Switch to another network such as Wi-Fi or a different hotspot, use Show saved translation for the examples, or run the model server (section 8).
"Translation failed: Could not download the translation model from huggingface.co" The connection dropped, or the network blocks huggingface.co. Click the button again, or use another network or the model server.
Translation is very slow the first time It is downloading about 900 MB. Watch the progress line; it only happens once per browser.
Badge still says "In-browser models" with the server running Check the terminal still shows the server, then click Analyse again (the page checks on every click). The server must use port 8765; close any other program on that port.
My added search articles disappeared They are kept only until the page is reloaded. Add them again.
The browser's developer console shows "connection refused" Harmless. It is the page checking whether the model server is running.

11Checklist before presenting

  1. Open the demo page on the presentation laptop and click through all three tabs once.
  2. On the network you will use for the presentation, click Translate to English once. This checks that the network allows it and saves the translation model. If that network blocks it, plan to use Wi-Fi, Show saved translation, or the model server.
  3. Copy a short Marathi news article (4–8 sentences) from a news site, ready to paste into the Full pipeline tab.
  4. Optional: start python app/server.py and run Analyse once, so the full models are already loaded.
  5. Keep this manual and the Explanation Guide open in another window.
